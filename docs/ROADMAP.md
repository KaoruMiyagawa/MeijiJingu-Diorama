# 后续路线图

当前已完成版本：**v1.2.0**（全园森林视觉版）。以下项目是待评估方向，不是已实现功能或时间承诺。优先级可根据视觉评审和目标运行设备调整。

## 已完成

- **v1.0.0 · 核心神社区**：精细主神社、南神门与围廊、鸟居、周边森林、晴日基础环境、自由观察与真实浏览器验收。
- **第二轮灰盒开发里程碑**：整理全园方向、入口、路网、分区与镜头范围；灰盒经过评审后仅作为布局验证阶段留档。
- **v1.2.0 · 完整内苑森林**：将核心建筑放入完整园区关系，加入 1,000 棵分块实例化森林、道路、御苑与池塘、附属设施和晴日光影。

## 建议的下一步

### P1 · 布局核对与比例信息

- 继续将官方地图、入口说明、园区公开资料与实际路径关系交叉核对。
- 为关键地标和路线节点记录出处、可信度和艺术近似范围；保持示意地图不被误用为测绘坐标。
- 依据视觉评审微调森林密度、道路宽度和地形高差，同时保留目前已验收的核心建筑尺度与固定镜头对照。

### P1 · 目标设备性能基线

- 在指定低端集显与真实移动设备上补充浏览器测试；分别测量加载、GPU/CPU 帧时、内存与触控流畅度。
- 基于数据决定像素比上限、阴影贴图、叶簇和远景植被预算；为画质降级提供明确档位。
- 评估按空间块裁剪/卸载远处树群的收益，避免未经实测盲目增加植被数量。

### P2 · 林间光影与环境细节

- 在不改变三渲二主风格的前提下，检查树冠内部遮蔽、道路斑驳阴影和不同树种色彩层次。
- 检查微风幅度、树冠运动相位和池面高光的可读性；提供减少动态效果时的静态表现检查。
- 评估地表石粒、砂砾、苔藓与树根细节的可读性和材质成本，避免重复纹理感。

### P2 · 场景易用性和可访问性

- 视觉评审后决定是否增加简洁的场景视角选择器或地标说明，不干扰当前纯画布展示。
- 进一步检查键盘聚焦、减少动态偏好、触控目标、屏幕阅读器说明和窄屏镜头取景。
- 如增加 UI，保持默认全园画面完整，不用界面元素遮挡场景主体。

## 暂不纳入本版

- 不重新制作或替换已经通过评审的神社建筑与鸟居模型。
- 不在没有目标设备数据前无节制提升树木数、叶簇数或阴影分辨率。
- 不宣称测绘级复原；未核实的地形、树种、建筑尺寸与路线细节继续标注为艺术近似。
- 不以强 Bloom、镜头眩光、浓雾或大范围景深模糊掩盖几何、阴影或材质问题。
- 不加入东京城市区、代代木公园或明治神宫外苑；当前范围仍为明治神宫内苑。
