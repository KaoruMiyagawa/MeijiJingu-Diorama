# 参考与空间设计

本项目在 2026-11-03 对照了官方园区地图、神社照片、鸟居照片与森林介绍。核对后的主要约束：

- 官方建筑说明明确为桧木木构与铜屋面，主殿采用前坡延长的流造。模型以深木、天然木与氧化铜绿为统一材料，前参拜檐突出。
- 南神门为双层建筑。模型保留开放门洞、二层立面和栏杆，连接左右围廊。
- 大鸟居为天然木色明神鸟居，官方尺寸高 12 m、宽 17.1 m。程序模型采用约 11.5 × 16.6 单位的近似比例，保留弯曲双层上梁、贯木和两根倾斜柱。
- 酒樽位于南参道，并有相对的葡萄酒桶展示。模型保留成排堆叠和木架，字样使用原创示意纹理。
- 森林由多种树种构成，不能表现成均匀行列的单一树木。程序使用固定种子的非规则分布，含冠形、颜色、枝干、高度差异，避免建筑与参道占位。

上述建筑依据见 [官方园区说明](https://www.meijijingu.or.jp/en/map/)，植被依据见 [官方森林介绍](https://www.meijijingu.or.jp/en/whattosee/forest/)。

## 空间压缩

坐标中北方为 -Z、南方为 +Z，底座覆盖 X/Z 的 [-40,40]。

| 区域 | 位置 | 构图目的 |
| --- | --- | --- |
| 入口与鸟居 | X≈13，Z≈27 | 入口视觉锚点，保留两柱完整轮廓 |
| 主要参道 | 南边缘至 X≈0，Z≈4 | 以缓弯将视线从入口引向神门 |
| 南神门 | X≈0，Z≈3 | 标记外部森林与内部前庭的过渡 |
| 庭院 | X≈±16，Z≈-7 | 参拜中轴、铺石、砂砾、庭院樟树 |
| 主参拜殿 | X≈0，Z≈-18 | 主要建筑体量与屋顶视觉中心 |
| 后部殿堂 | Z≈-24 至 -29 | 增加真正三维的纵深与背面结构 |
| 内苑压缩景观 | X≈-25，Z≈18 | 小型静池与林间路径，次于建筑主体 |

这张模型不是官方地图按比例缩放的副本。入口、鸟居与酒樽的距离、方位关系经过压缩；没有声称复原全部建筑或精确场地距离。

## 取舍

采用 Three.js 原生模块及程序化几何，无需 Blender 或额外模型下载。所有复杂构件都是网格，建筑不是图片牌。重复静态构件在生成后按材质合并；树木则用实例化保留丰富轮廓。采用正交投影强化独立微缩收藏模型的感觉。

使用暖日光、天空补光和几何投影，不使用 Bloom、景深和浓雾。天空以干净的淡蓝展示环境表现，没有云层和地平线贴图。道具与森林中景优先于可选人物动画。
