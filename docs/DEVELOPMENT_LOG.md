# 开发记录与验收档案

此文档记录可由现存源码、测试报告和截图交叉核验的开发节点。项目最初没有本地 Git 仓库，目标 GitHub 仓库也为空；因此这里的历史来自保留的设计/验收文档和基线快照，不伪造逐日 Git 提交记录。

## 2026-11-03 · v1.0.0 神社核心区

### 交付内容

- 以真实神社建筑为主题制作可自由旋转观察的微缩场景，包含主殿、南神门、围廊、木构、曲面屋顶、鸟居、参道、酒樽和周边森林。
- 以 Three.js 程序化几何和材质构建场景；使用正交相机、阴影、共享/合并网格与实例化植被，形成低多边形三渲二风格。
- 增加主建筑、鸟居、俯视、反向和竖屏等视觉检查视角，并保留鼠标和触控观察能力。

### 重要决策

- 复杂建筑以三维网格建模，不用图片牌替代；重复构件共享材质与几何。
- 官方地图与建筑说明用于理解空间和建筑形式，不声称是精确测绘复原。
- 保留固定镜头截图、基线源码 SHA256 清单和独立恢复 ZIP。

### 验收记录

- `npm run build` 成功；`npm test` 的 25 项第一版检查通过。
- 本机 Chrome 156 / WebGL2 / NVIDIA RTX 5060 Laptop，默认场景约 129 Draw Calls；RAF 帧间隔中位数约 4.2 ms、P95 约 4.3 ms。样本和验收范围见 [`docs/VALIDATION.md`](VALIDATION.md) 及首版恢复档案中的 `captures/verification.json`。
- 视觉检查修正了参道路面绕序、铜屋顶法线、入口树冠遮挡、森林后部断层、竖屏裁切和镜头切入树冠等问题。

## 2026-11-05 · 第二轮全园布局灰盒

- 建立可维护的园区布局数据，定义北向、相对入口位置、参道节点关系、建筑区、御苑、池塘和北部设施。
- 首次把范围扩展至约 280 × 280 世界单位，并加入全园视角、俯视、南/北/西入口及核心近景镜头。
- 为地形高度、道路、区域边界、场景分区和后续植被空间管理预留接口。
- 首版晴日样片加入天空、方向性日光和补光，保留原始核心区作为对照。

### 评审结论与后续决定

- 灰盒虽然验证了布局与相机范围，但视觉上像规划图，不能作为最终质量版本。
- 不扩建粗糙占位块；改为沿用第一版树木和建筑美术语言，为全园制作分层森林、真实道路曲面、庭园地表和风格化附属建筑。该阶段仍由 [`docs/ROUND-2-VISUAL-PLAN.md`](ROUND-2-VISUAL-PLAN.md)、[`docs/ROUND-2-BATCH-1.md`](ROUND-2-BATCH-1.md) 与 `captures/round2/` 留档。

## 2026-11-05 · v1.2.0 全园森林与晴日环境

### 完成内容

- 默认场景扩展至完整内苑森林园区，包含三个主要方向入口、南/北/西侧参道、神社建筑区、御苑与南池、北部景观、宝物殿及附属设施。
- 复用第一版神社模型和既有森林造型；保持第一版核心建筑、屋顶、围廊、鸟居和基础材质源文件不变。全园版本对组装后的派生模型局部开通西侧通道，不破坏独立核心区。
- 新增园区高度场、路网/地标数据、边界与区域查询、植被冲突避让、空间分块森林以及动态全园镜头边界。
- 以 `InstancedMesh` 将 1,000 棵树分在 23 个空间块，使用多层树冠与分级细节、灌木和微风表现大范围森林，而非单纯放大底座或复制一圈相同树木。
- 建模园区道路、草地、池岸和庭园，并增加风格化宝物殿、御苑设施、博物馆、手水舍与酒樽设施。
- 优化晴日环境：浅蓝渐变天空、东京上午方向的暖白主光、略冷环境补光、树冠/建筑接触阴影与水面轻微扰动；不以 Bloom、强眩光、雾或景深掩饰结构。

### 浏览器视觉验收

- 最新真实浏览器截图保存在 [`captures/forest-20261105/`](../captures/forest-20261105/index.html)：包含全园、俯视、三个入口、神社、御苑、宝物殿、林间道路、西门、竖屏和固定构图的第一版核心区对照。
- 画面由安装版 Chrome 156 在 WebGL/ANGLE/D3D11 与 NVIDIA RTX 5060 Laptop 上实时生成；1920 × 1080、DPR 1。截图没有经 AI 生成或后期替换。
- 全园默认视角：489 Draw Calls、4,894,946 个三角形提交；中位 RAF 间隔 4.2 ms、P95 4.4 ms。神社近景：481 Draw Calls、7,684,110 个三角形提交；中位 4.2 ms、P95 8.5 ms。
- 29 项自动检查通过，覆盖构建、基线哈希、路网/地标、植被避让、森林覆盖、LOD、相机交互与边界、镜头过渡、触控模拟、竖屏、西门射线通道、核心区固定镜头与截图、资源和运行错误。
- 这些 RAF 间隔包含浏览器显示调度，不等于 GPU 单独耗时；桌面 Chrome 触控模拟也不能替代真机测试。完整原始记录见 [`verification.json`](../captures/forest-20261105/verification.json)。

### 数据准确性与已知边界

- 园区相对关系依据明治神宫官方地图与景点资料。示意地图不是测绘图；具体地界、树位、地形细节、岸线和附属建筑尺寸均是艺术近似。
- 树冠在自由观察时可能遮挡建筑；没有自动透明树木。全园远景阴影、近远树冠转换与水面反射仍可继续打磨。
- 目标硬件为本机 RTX 5060 Laptop；未对真实手机或低端集显做性能认证。
