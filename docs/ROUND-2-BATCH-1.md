## 全园布局与准确性边界

展台为 **280 × 280** 世界单位，边长为第一版的 3.5 倍、面积为 12.25 倍。场景不是第一版整体缩放：保留建筑维持原尺寸，移到 `[-18, 0.9, -8]`；重新建立不规则园区边界、路网、御苑、池塘和森林分区。展台留边不代表神宫土地，不把代代木公园或外苑纳入模型。

坐标约定：+Y 向上，−Z 为北，+X 为东。地标数据包含唯一 ID、模型坐标、区域、参考来源及可信度。源码中的 `position.y=0` 为平面锚点，运行时用 `heightAt(x,z)` 解算地面高度；`captures/round2/layout.json` 同时导出 `planPosition` 和解算后的三维 `position`，以及区域包围盒、道路节点、连接和采样。

## 晴日样片

核心区保留 274 棵树、6,463 个树冠实例、47,830 个细叶簇和 797 个灌木实例。位置、随机种子、建筑大小、屋顶细节、相机构图及曝光不变。

- 天空改为清澈浅蓝的克制渐变；展示底座周边使用透明承影面与柔和接地贴片，去除遮满视野的灰白摄影棚地面。该天空是展示用二维渐变，并非物理大气散射。
- 主光采用东京 **6 月 1 日、上午 10:00 JST** 的近似太阳方向，北向统一为 −Z；光源在东偏南上空，投影落向西偏北。采用 [NOAA 分数年太阳位置近似公式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)。这是固定夏季晴日上午样片，不是按当前系统日期实时计算天气。
- 暖白主光强度保持 3.1，配合略冷天空补光，形成受光与背光差别；没有整体加曝光。保留 4096 阴影贴图，重新调整方向、覆盖范围及偏移。全园阴影范围随镜头视野调整并做光空间像素对齐，核心区对照使用固定范围。
- 树叶保留 Toon 材质和原 GPU 风动；增加克制的局部叶簇上下色差，调整色阶，结合真实树冠投影强化层次。此局部着色不是体积 AO 或真实全局光照。
- 参道增加细砂砾凹凸；树皮、地表增加微弱凹凸；木材和铜屋面调整粗糙度。原有苔色地表、杂草和自然层次继续沿用。
- 未增加 Bloom、镜头眩光、雾、景深、SSAO 或 GI 后处理。透明底座承影贴片只负责展台接地，不冒充树根或建筑接触阴影；后者仍由实际几何投影与材质承担。

## 性能与验证

2026-11-03，Windows，Chrome **156.0.8078.48**，ANGLE / NVIDIA **RTX 5060 Laptop GPU**，WebGL2，1920 × 1080、DPR 1，生产 `dist/`，默认全景。每场景新建浏览器上下文，预热 1.2 秒，再取 240 个 RAF 帧间隔。

| 场景 | Draw Calls | 三角形提交 | 导航至首帧 | 帧间隔中位 | P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 第一版基线 | 129 | 3,956,717 | 988 ms | 4.2 ms | 4.3 ms |
| 全园灰盒 | 148 | 550,916 | 1,089 ms | 4.2 ms | 4.4 ms |
| 晴日核心区 | 130 | 3,956,719 | 758 ms | 4.2 ms | 4.4 ms |

计数为 `renderer.info.render` 提交量，包含阴影绘制，不是唯一模型面数。灰盒 Draw Calls 较高来自分区、地标和地图文字的独立绘制，当前不代表性能瓶颈。核心区仅新增 1 次提交和 2 个三角形提交；几何结构保持不变。

**测量限制：** RAF 间隔包含显示调度，不是独立 GPU 耗时；首帧时间包含自动化轮询，且未清除系统文件缓存及 GPU 驱动缓存，因此不是严格冷启动对比，不能据此声称核心区加载更快。数据仅来自本机，尚无低端 GPU、集显或真实手机性能保证。交互测试中的移动设备是 Chrome 触控模拟。原始数据：`captures/round2/verification.json`。

`npm run build` 成功；`npm test` **46 项检查通过**，无运行 / WebGL 错误、无警告、无资源请求失败。验证覆盖：基线和保留模块哈希、地标来源、路网连通性、道路中心线不穿森林占位体或池塘、地形查询、区域包围盒、正交屏幕尺寸 LOD 与滞回、两种场景的鼠标和触控操作、预设动画、边界、竖屏，以及四组相机对照。

## 尚未解决 / 下轮评审项

1. **真实比例与高程**：官方导览图不是测绘底图。完整范围与主要空间关系已落入灰盒，但边界曲折、距离、地形、御苑小径、建筑体量及池岸仍需进一步校准；不能将本模型用作导览导航或比例测量。
2. **西门接口**：西侧参道终止在原围廊外 `[-38, heightAt, -16]`。为了保留第一版围廊，本批没有擅自切开西门，也没有让道路穿墙。该入口与庭院的实物连接是明确待办，需在建筑扩展评审后实施。
3. **周边建筑与庭园**：宝物殿、至诚馆、博物馆、Forest Terrace、隔云亭及酒樽设施仅为体量标识，未完成真实建筑细节；没有虚构未确认的小路填充空白。
4. **森林扩建**：当前全园只有 10 个占位体，没有批量复制第一版森林。LOD 屏幕尺寸判定、滞回和区域包围盒已做最小验证，但完整树木分块、异步流式加载、实例池和逐区裁剪还未实施；既有核心区仍使用原 Instancing。
5. **阴影与暗部**：晴日方向和层次已改变，深檐、林下及深色铜屋面是否过暗需视觉评审。全园远景共享 4096 阴影，远距离精度受限；近景切换时阴影覆盖范围变化仍可能看到轻微质量变化。尚无专门的树根/柱脚 AO、面积光软阴影或 GI。
6. **地形接缝与路面**：已修复池岸叠层闪烁及占位森林遮路，并检查路网中心线。极近距离的道路宽度边缘、道路与神门地面的小高差仍属于灰盒衔接，未作为可行走碰撞地形验收。
7. **画面表现**：天空为渐变展示环境；灰盒标识是放在地面上的文字，极低视角可读性有限。晴日样片用于评审三维光照与材质，不代表最终动画背景美术完成度。
8. **性能覆盖**：只测了本机独显，下一阶段需在确定目标设备后建立实际预算；未以规划中的 400–600 万面、250–350 Draw Calls 为硬性目标。

本批交付到此，后续高精度森林、真实建筑扩建和进一步渲染改动等待下一轮视觉评审。
